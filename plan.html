La premisa

Repasar sin aburrirse

La inspiración es la misma que hace funcionar a GameCode/Webcraftia y a Duolingo: lecciones cortas, un editor de código real integrado en la página (sin instalar nada), validación instantánea de cada reto, y una recompensa visible apenas se resuelve algo. Nada de video-clases largas ni exámenes — cada tema se aprende escribiendo código de verdad y viendo si funciona.

La diferencia con esas plataformas es el tamaño: esto es para ustedes dos, así que no hace falta un sistema de cuentas, ni multi-idioma, ni siete lenguajes distintos. Un solo lenguaje (Python), cuatro mundos bien elegidos, y una progresión que ambos puedan ver y comparar.

Anatomía de una lección

Cómo se ve un reto por dentro

Ejemplo real, tomado del Mundo 2 (ciclos), para que quede claro el formato antes de construirlo:

Reto · Mundo 2, lección 3

Un mercader cuenta sus monedas del 1 al 20 en voz alta, pero cada vez que llega a un múltiplo de 3, grita "¡Pum!" en lugar del número. Completa el ciclo para que el programa haga lo mismo.

# tu código va aquí
for moneda in range(1, 21):
    if moneda % 3 == 0:
        print("¡Pum!")
    else:
        print(moneda)
Recompensa: +15 XP · 2 pistas disponibles · validación automática al ejecutar
Cómo se construye

Arquitectura técnica, en corto

Motor de código

Python real corriendo en el navegador (Pyodide, Python compilado a WebAssembly) — cada uno escribe y ejecuta código sin instalar nada ni depender de un servidor.

Validación

Cada reto compara la salida del programa contra el resultado esperado y da el ✅ o señala en qué línea revisar, con pistas progresivas si se traban.

Progreso

Se guarda el avance de cada uno por separado — mundo actual, XP, racha e insignias — para retomar exactamente donde quedó cada quien.

Cuentas

Nada de registro ni contraseñas: al ser solo ustedes dos, basta con elegir "Jugador 1" o "Jugador 2" al entrar.
